# Posts API

Manage posts programmatically. All endpoints require [authentication](/api/authentication) and return JSON.

Base URL: `https://app.updates.page`

## List posts

```
GET /api/v1/posts
```

Optionally filter by status with `?status=draft`, `?status=published`, or `?status=scheduled`.

```bash
curl "https://app.updates.page/api/v1/posts?status=published" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Returns an array of posts:

```json
[
  {
    "id": 42,
    "title": "New: Dark mode is here",
    "created_at": "2026-07-01T09:15:00Z",
    "updated_at": "2026-07-02T14:30:00Z",
    "published_at": "2026-07-02T14:30:00Z",
    "category_id": 3,
    "is_public": true,
    "status": "published",
    "portal_url": "https://yourcompany.updates.page/changelog/new-dark-mode-is-here"
  }
]
```

## Get a post

```
GET /api/v1/posts/:id
```

Returns the full post, including its content, summary, category, and cover image.

```bash
curl https://app.updates.page/api/v1/posts/42 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```json
{
  "id": 42,
  "title": "New: Dark mode is here",

  "summary": "You can now switch to dark mode from your profile menu.",
```

## Create a post

```
POST /api/v1/posts
```

Creates a draft post. `content` is HTML. `category_id` is optional — see the [Categories API](/api/categories) to list your category IDs.

```bash
curl -X POST https://app.updates.page/api/v1/posts \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "post": {
      "title": "New: Dark mode is here",
      "content": "<p>You can now switch to dark mode from your profile menu.</p>",
      "category_id": 123
    }
  }'
```

Returns the created post.

## Publish a post

```
POST /api/v1/posts/:id/publish
```

Publishes a post immediately:

```bash
curl -X POST https://app.updates.page/api/v1/posts/42/publish \
  -H "Authorization: Bearer YOUR_API_KEY"
```

To schedule it instead, pass an ISO 8601 `published_at` in the body:

```bash
curl -X POST https://app.updates.page/api/v1/posts/42/publish \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"published_at": "2026-08-01T09:00:00Z"}'
```

## Unpublish a post

```
POST /api/v1/posts/:id/unpublish
```

Reverts a published post to a draft:

```bash
curl -X POST https://app.updates.page/api/v1/posts/42/unpublish \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## Delete a post

```
DELETE /api/v1/posts/:id
```

```bash
curl -X DELETE https://app.updates.page/api/v1/posts/42 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Warning>
  Deleting a post is permanent.
</Warning>
