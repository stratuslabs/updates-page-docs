# Portal Customization

Customize your changelog portal in **Settings → Portal → Customize**. Changes save as you go.

## Template

Start from one of four layouts, on every plan:

| Template | Look |
|----------|------|
| **Minimal** | A quiet left rail with content-first cards |
| **Modern** | Clean and minimal, with cards |
| **Classic** | Dark theme, two-column layout |
| **Cards** | Light theme, colorful cards |

Switching templates keeps your content and colors — it changes the layout only.

## Header

- **Logo** — .jpg or .png, plus an optional link to your own site and a size setting
- **Title** and **Description** — the headline and subtitle at the top of your changelog
- **Colors** — header text and background
- **Background image** — a header backdrop (**Pro** and above)

## Page and posts

| Setting | Description |
|---------|-------------|
| **Width** | How wide the content column is |
| **Background color** | Main page background |
| **Filter sidebar** | Show or hide the category filter |
| **Navigation labels** | Rename the Posts link, or add a link back to your site |
| **Post content** | Show full posts in the list, or summaries only |
| **Post styling** | Colors, border radius, shadow, and padding |

## Custom CSS

For anything the settings don't cover, add your own CSS under **Advanced → Custom CSS**. It's injected into your portal on every page.

```css
/* Example: a serif font for post titles */
#Portal h1 {
  font-family: Georgia, serif;
}
```

<Warning>
  The portal's markup uses utility classes that can change between releases, so target elements by tag or structure where you can, and re-check your CSS after a redesign. Custom CSS can break your portal — test changes before saving.
</Warning>

## Preview

The Customize page shows a live preview of your portal as you edit, so you can see each change before you leave the page.
