## Embed types

updates.page offers two embed types:

### Widget embed

A floating button that opens a slide-out panel with your announcements.

**Best for:**
- SaaS apps and dashboards
- "What's new" button in navigation
- Unobtrusive changelog access

### Inline embed

Announcements displayed directly on your page, styled to match your site.

- Marketing websites
- Changelog pages
- Documentation sites

## Quick comparison

| Feature | Widget | Inline |
|---------|--------|--------|
| Installation | 1 script tag | 1 script tag + container |
| Visibility | On-demand (click to open) | Always visible |
| Customization | Colors, position | Full CSS control |
| "New" badge | ✓ | ✗ |
| Best for | Apps | Websites |

## Creating an embed

<Steps>
  <Step title="Go to Embeds">
    Navigate to **Settings → Developer → Embeds**
  </Step>
  <Step title="Create new embed">
    Click **New Embed** and choose Widget or Inline
  </Step>
  <Step title="Configure">
    Set the name, style, and options
  </Step>
  <Step title="Copy the code">
    Copy the generated script tag to your site
  </Step>
</Steps>

## Embed settings

Each embed can be configured with:

| Setting | Description |
|---------|-------------|
| **Name** | Internal name for your reference |
| **Type** | Widget or Inline |
| **Position** | (Widget only) Bottom-left or bottom-right |
| **Theme** | Light or dark mode |
| **Categories** | Filter which categories to show |

## Managing embeds

You can create multiple embeds for different use cases:

- One widget for your main app
- One inline embed for your marketing site
- Different category filters for different audiences

Edit or delete embeds anytime in **Settings → Developer → Embeds**.
