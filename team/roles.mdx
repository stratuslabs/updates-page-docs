# Roles & Permissions

Every account has one **owner**. Everyone they invite joins as a **member**.

## Available roles

| Role | Description |
|------|-------------|
| **Owner** | Full access to everything, including billing, settings, and the team |
| **Member** | Writes, publishes, and manages posts |

<Note>
  Invited teammates are always members. Roles can't be changed after an invite is sent yet — if you need a different arrangement, [contact us](mailto:hey@updates.page).
</Note>

## Permission matrix

| Permission | Owner | Member |
|------------|-------|--------|
| Create, edit, and delete posts | ✓ | ✓ |
| Publish and schedule posts | ✓ | ✓ |
| View reports | ✓ | ✓ |
| Manage categories | ✓ | ✗ |
| Import from an RSS feed | ✓ | ✗ |
| Portal settings and custom domain | ✓ | ✗ |
| Embeds and API keys | ✓ | ✗ |
| Invite and remove members | ✓ | ✗ |
| Billing & subscription | ✓ | ✗ |

<Note>
  Posts are shared, not personal: any member can edit or delete any post on the account, including drafts written by someone else.
</Note>

## What members see

Members see Posts and Reports, plus their own **Account → Profile** and **Notifications** settings. Everything else in Settings is hidden from them and refused by the API.
